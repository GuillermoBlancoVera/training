## Objectives

- Understand the logic behind a program.
- Write and read basic code with confidence.

## Curriculum

- Variables, types and conditions
- Loops, functions and data structures
- Errors, debugging and code organisation

## Methodology

Short explanations and incremental exercises, focusing on reasoning rather than memorising syntax.
