## Objectives

- Handle the main elements of the Python language.
- Solve simple tasks and reuse code.

## Curriculum

- Syntax, variables and data structures
- Functions, modules and files
- Errors and debugging
- Introduction to APIs and practical exercises

## Methodology

Learning by doing: each block ends with a small program that consolidates what was covered.
