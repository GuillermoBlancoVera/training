## Objectives

- Build a simple Cloud architecture end to end.
- Apply least-privilege permissions, logging and reproducible deployment.

## Curriculum

- API Gateway, Lambda, DynamoDB and S3
- IAM and CloudWatch
- Introduction to Infrastructure as Code
- Design, deployment and observability

## Methodology

Hands-on workshop in blocks, with a starter repository and a review of architecture decisions.
