## Objectives

- Understand AWS global infrastructure and its main services.
- Learn the basics of security, cost and monitoring.
- Be able to read a basic AWS architecture.

## Curriculum

- Global infrastructure and the shared responsibility model
- IAM, EC2, S3, Lambda, RDS and DynamoDB
- API Gateway and basic architectures
- CloudWatch, security and cost

## Methodology

Essential concepts combined with a guided demo and an architecture exercise.
