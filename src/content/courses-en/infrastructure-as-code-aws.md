## Objectives

- Understand the benefits and limits of Infrastructure as Code.
- Create maintainable stacks ready for multiple environments.

## Curriculum

- IaC principles and AWS CDK
- Stacks, resources, configuration and environments
- Deployments, CI/CD and security
- Good practices for structure and maintenance

## Methodology

Workshop with code and a review of a realistic project structure.
