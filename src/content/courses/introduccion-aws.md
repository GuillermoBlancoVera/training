## Objetivos

- Comprender la infraestructura global de AWS y sus servicios principales.
- Conocer las bases de seguridad, costes y monitorización.
- Saber interpretar una arquitectura AWS elemental.

## Temario

- Infraestructura global y modelo de responsabilidad compartida
- IAM, EC2, S3, Lambda, RDS y DynamoDB
- API Gateway y arquitecturas básicas
- CloudWatch, seguridad y costes

## Metodología

Conceptos esenciales combinados con una demostración guiada y un ejercicio de arquitectura.
