## Objetivos
- Construir una arquitectura Cloud sencilla de extremo a extremo.
- Aplicar permisos mínimos, logs y despliegue reproducible.

## Temario
- API Gateway, Lambda, DynamoDB y S3
- IAM y CloudWatch
- Introducción a Infrastructure as Code
- Diseño, despliegue y observabilidad

## Metodología
Taller práctico por bloques, con repositorio base y revisión de decisiones de arquitectura.
