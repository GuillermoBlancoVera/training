## Objetivos
- Manejar los elementos principales del lenguaje Python.
- Resolver tareas sencillas y reutilizar código.

## Temario
- Sintaxis, variables y estructuras de datos
- Funciones, módulos y archivos
- Errores y debugging
- Introducción a APIs y ejercicios prácticos

## Metodología
Aprendizaje haciendo: cada bloque termina con un pequeño programa que consolida lo visto.
