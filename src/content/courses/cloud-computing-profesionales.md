## Objetivos

- Entender qué aporta Cloud Computing y cuándo tiene sentido.
- Diferenciar IaaS, PaaS y SaaS con ejemplos prácticos.
- Tener un marco para conversar con equipos técnicos y proveedores.

## Temario

- On-premise frente a Cloud
- Modelos de servicio y responsabilidad compartida
- Regiones, zonas de disponibilidad y escalabilidad
- Seguridad, costes y gobernanza
- AWS, Azure y Google Cloud: visión comparativa
- Casos de uso reales

## Metodología

Explicación visual y accesible, conectada con escenarios de producto, datos y sistemas empresariales.
